# Бот для занятий украинским языком

Репозиторий: https://github.com/maxseryogin/ukr-lang. Для работы без включённого компьютера: [пошаговый запуск на Railway](RAILWAY.md).

Ученик: **1374449699**. Преподаватель: **1252270301**. Доступ только этим двум аккаунтам, в личных сообщениях.

## Что делает

- Получает от преподавателя PDF, текст со ссылкой на практику и голосовое. После `/publish` отправляет их ученику в том же порядке. Голосовое остаётся голосовым, PDF — файлом, подписи и ссылки сохраняются. Файлы повторно отправляются по Telegram file_id; распознавания или пересказа PDF нет.
- В пятницу и субботу спрашивает о текущей теме в **17:00, 18:00, 19:00, 20:00, 21:00 и 22:00 по Киеву**. Время принято как вечернее. Меняется в `.env`.
- Кнопка **«Точно прошёл тему»** завершает занятие и отключает напоминания об этой теме, включая субботние после завершения в пятницу. Преподаватель получает уведомление. Проверки знаний нет — на совести ученика.
- После завершения предлагает оценку **1–5 звёзд**, отправляет её преподавателю. Одна оценка на тему.
- Кнопка **«Запросить следующую тему»** доступна сразу и после завершения. Запрос приходит преподавателю один раз на тему. Материалы отправляются после публикации преподавателем. Пока текущая тема не завершена, следующую можно подготовить как черновик.
- Незавершённая тема продолжает получать напоминания в следующие пятницы и субботы. Без активной темы напоминаний нет.
- Сохраняет темы, оценки, очередь сообщений и прогресс в SQLite. Перезапуск не сбрасывает состояние.

## Первый запуск на Windows

1. Создай бота через [@BotFather](https://t.me/BotFather): команда `/newbot`. Скопируй полученный токен.
2. Установи [Python 3.11 или новее](https://www.python.org/downloads/), если его нет. Открой PowerShell в этой папке.
3. Выполни:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

4. В `.env` замени `PASTE_TOKEN_HERE` на токен. Не публикуй `.env` и не присылай токен в чат. ID уже указаны.
5. Запусти:

```powershell
.\.venv\Scripts\python.exe bot.py
```

6. **Вы оба должны открыть бота в Telegram и нажать Start / отправить `/start`.** Одного ID недостаточно, чтобы бот начал переписку с человеком: [правила Telegram](https://core.telegram.org/bots#how-do-bots-work).

Бот работает, пока запущен процесс и есть интернет. Если компьютер выключен или спит, напоминаний не будет. Для постоянной работы используй сервер или постоянно включённый компьютер. Для одного токена запускай только один экземпляр.

## Как отправить занятие

В личном чате с ботом с аккаунта **1252270301**:

1. Отправь `/new Апостроф в українській мові`.
2. Прикрепи презентацию **файлом PDF**.
3. Отдельным сообщением отправь ссылку на практику с пояснениями.
4. Отправь или перешли голосовое сообщение.
5. Отправь `/publish` — ученик получит тему и материалы.

Можно добавить несколько PDF, ссылок или голосовых; для публикации достаточно одного материала. `/cancel` удаляет только черновик. Опубликованную тему эта команда не меняет.

Ученик использует кнопки под занятием. `/status` снова показывает кнопки текущей темы. `/next` запрашивает следующую, в том числе первую, если занятий пока нет. Преподавателю `/status` показывает текущую тему, последний результат и наличие черновика.

## Постоянный запуск через Docker

Нужен установленный Docker с Compose. Заполни `.env`, затем в этой папке:

```sh
docker compose up -d --build
docker compose logs -f --tail=50
```

Контейнер перезапускается после сбоев и перезагрузки хоста, когда запускается Docker. База хранится в `./data/`. Остановка: `docker compose down`. Не удаляй `data/`, если нужен прогресс. Резервную копию `data/` делай при остановленном боте. Токен передаётся через окружение, в образ не включается.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

Тесты используют поддельный Telegram API: проверяют расписание и границы часов, обе даты, прекращение напоминаний, оценку, права доступа, публикацию материалов, восстановление после перезапуска и очередь при ошибках доставки. Для проверки реальной доставки нужен твой токен и `/start` обоих пользователей.

## Поведение при сбоях

Обычные сообщения и материалы сохраняются в очереди до успешной отправки. Если ученик ещё не нажал `/start`, заблокировал бота или Telegram недоступен, отправка повторяется; преподаватель получает сообщение о первой ошибке доставки. Порядок материалов сохраняется. При постоянной ошибке сообщение задерживает последующие сообщения этому адресату; причина видна в журнале по коду Telegram. После разблокировки отправка восстановится автоматически.

Напоминания создаются в течение первой минуты указанного часа, могут прийти на несколько секунд позже из-за polling. Через 5 минут недоставленное напоминание удаляется, чтобы не присылать устаревшие вопросы. Пропущенные при выключенном боте часы не догоняются. Если Telegram принял сообщение, но соединение оборвалось до ответа, повтор может создать дубликат: API не предоставляет ключей идемпотентности для отправки.

Настройки: `TIMEZONE=Europe/Kyiv`, `START_HOUR=17`, `END_HOUR=22`; границы включены. Часовой пояс автоматически учитывает перевод часов согласно установленной базе tzdata. Дни недели заданы в `bot.py`: `(4, 5)` — пятница и суббота. Бот работает через [официальный Telegram Bot API](https://core.telegram.org/bots/api); OpenAI API и платная модель для него не требуются.
